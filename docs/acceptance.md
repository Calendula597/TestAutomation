## 真实执行边界

- Android 验收使用专用模拟器，不执行日常设备；测试结束关闭模拟器。Appium 会话发现只在回环测试服务开启，生产服务没有放宽该安全设置。
- k6 只运行单个授权 Worker 的受限 HTTP/HTTPS 压测，不包含分布式压测或未经确认的目标。
- 其他语言通过通用原始报告导入保存，不宣称已原生执行其测试工具或采集覆盖率。
- 外部模型提供方需要用户批准的凭据；当前验证的是受控 Agent 协议、工具约束、澄清、引用和错误路径，不宣称完成真实模型质量或人工业务质量评审。
- 报告与证据可能包含业务信息，通过项目授权读取；数据库备份包含敏感数据，必须存储在受限持久目录。

## 未验收与明确限制

- iOS 没有 macOS/Xcode 节点，未验收。
- Firefox、WebKit 未验收；Web 当前只验证 Chromium。
- Android 仅验证 Android 14 模拟器上的原生演示 APK；未验证真机、其他系统版本或 Hybrid APP。
- Windows 仅验证 WinForms 演示应用；Win32、WPF、UWP 等其他应用类型未逐一验收。
- Electron 不支持原生系统对话框；主进程验证只使用应用显式测试钩子。
- 客户实际 Web/API 系统、真实账号和生产负载未验收；演示结果不是生产容量承诺。
- 非 TS/JS 语言的原生白盒插桩未实现，仅提供报告导入。
- Appium 上游依赖仍有 moderate 告警；没有通过未经验证的强制升降级消除告警。

## 发布检查原则

所有真实执行都保留状态、原因、版本与证据；基础设施错误是 `ERROR`，业务断言失败是 `ASSERTION_FAILED`。取消与超时分别为 `CANCELLED` 和 `TIMED_OUT`，不能相互替换。临时 SQL、容器、浏览器、应用进程、模拟器与恢复数据库必须清理；密钥、原始令牌、SDK、APK、证据和日志不能进入提交。
